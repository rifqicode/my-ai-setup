# Qark — Antigravity bootstrap

For software development tasks, invoke the installed `qark` skill before implementing changes. Apply Impact-Driven Planning: execute explicitly authorized isolated low-risk edits directly, investigate uncertainty, and require a user-approved Technical Plan before material business, security, data or architectural changes.

For bugs, test failures or unexpected behavior, check for `systematic-debugging` and read it if accessible; otherwise use Researcher's evidence-first investigation. Do not install third-party skills silently or assume a specialist launched without evidence. Respect user intent, existing file changes, and separate deployment authorization.

This is only a lightweight discovery rule. Canonical workflow: `skills/qark/SKILL.md` and root `SKILL.md`.
