# Qark global startup bootstrap

For software-development requests (features, bugs, refactors, tests, code review, architecture and implementation planning), **check for the installed Qark skill and read its SKILL.md before starting the task**. Apply Qark's intent/impact routing; do not automatically force full planning or spawn agents for trivial or read-only tasks.

Use Qark's approved plan, Grill Me, Code Reviewer, QA, and optional Herdr routing as applicable. Keep any user's explicit request not to use Qark authoritative. If Qark is missing or inaccessible, proceed normally and say so when it affects the work. Never pretend a skill or subagent was loaded. Do not install anything silently.

This file is a minimal discovery instruction, not a copy of Qark's full workflow.
